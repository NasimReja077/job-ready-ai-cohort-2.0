1. Builds a Docker image -> docker build . - t cohort-class

2. Runs a container based on a Docker image -> docker run cohort-class

3. Lists running containers. -> docker ps

4. Stops a running container -> docker stop <container-id or container-name>

5. Removes a stopped container -> docker rm <container-id or container-name>

6. Removes a Docker image -> docker rmi <image-id or image-name>
